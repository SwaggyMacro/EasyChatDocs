## 语言

| 选项 | 作用 |
| --- | --- |
| 界面语言 | 设置 EasyChat 软件显示语言、按钮和提示文字使用的语言。 |
| 母语语言 | 指定用户熟悉的语言（母语），供翻译、语音识别等功能作为默认目标语言或辅助语言参考。 |
| 源语言 | 设置全局翻译源语言；选择“自动检测”时由翻译引擎判断输入语言。 |
| 目标语言 | 设置全局翻译目标语言。输入翻译、截图翻译和划词功能在选择“跟随全局设置”时使用此值。 |

## 关闭与启动

| 选项 | 作用 |
| --- | --- |
| 关闭行为 | 选择关闭主窗口时“询问”、“退出应用”或“最小化到托盘”。最小化到托盘可让软件、快捷键继续工作。 |
| 开机自启动 | 控制系统登录后是否自动启动 EasyChat。 |
| 全屏 | 让主窗口以全屏方式显示。 |

## 外观

| 选项 | 作用 |
| --- | --- |
| 基础主题 | 选择跟随系统、浅色或深色主题。 |
| 颜色主题 | 在基础主题上选择预设强调色；自定义主题时使用下方颜色值。 |
| 自定义主色 | 设置界面的主要强调颜色。填写有效的颜色值（例如 `#2F80ED`）。 |
| 自定义强调色 | 设置按钮、选中状态等控件的强调颜色。 |

## 应用数据与网络

| 选项 | 作用 |
| --- | --- |
| 应用数据目录 | 查看或更改设置、提示词、模型清单等所有本地数据的保存位置。|
| 网络代理 | 选择使用系统代理、不使用代理或自定义代理。自定义模式需填写代理地址；此代理用于模型下载、语音模型、更新等通用网络请求。AI 大模型和机器翻译可在各自设置中单独决定是否使用代理。 |
