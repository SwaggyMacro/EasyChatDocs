## AI 大模型

可添加多个自定义模型配置，并在其他功能中选择使用的模型。

| 选项 | 作用 |
| --- | --- |
| 名称 | 在 EasyChat 中显示的模型配置名称，便于区分不同服务。 |
| 模型类型 | 选择 OpenAI、Gemini、Claude、DeepSeek 或 Custom，以决定请求协议和默认参数。 |
| API Key | 服务商颁发的访问密钥。支持维护多个 Key，便于轮换或分担限流。 |
| API 地址 | 模型服务的请求地址；使用 Custom 或兼容 OpenAI API 的网关时填写。 |
| 模型 | 要调用的模型标识，例如服务商文档中的 model 名称。 |
| 使用代理 | 控制该 AI 模型请求是否经过通用网络代理。 |
| 启用思考 | 对支持思考/推理的模型开启推理过程能力，可能增加响应时间和用量。 |
| 测试连接 | 使用当前配置发起测试请求，确认地址、密钥和模型可用。 |

## 机器翻译

支持百度、腾讯、Google 和 DeepL。每个服务都有独立的启用代理开关、服务 ID 和凭据。

| 服务 | 需要配置的字段 | 作用 |
| --- | --- | --- |
| 百度翻译 | App ID、App Key | 使用百度翻译开放平台凭据调用翻译。 |
| 腾讯翻译 | Secret ID、Secret Key | 使用腾讯云机器翻译凭据调用翻译。 |
| Google 翻译 | Model、API Key | 选择 Google 翻译模型并维护 API Key。 |
| DeepL | Model Type、API Key | 选择 DeepL 模型类型并维护 API Key。 |

每个服务的“使用代理”只影响该服务；“测试连接”用于验证当前凭据。请在服务商控制台申请密钥，EasyChat 不内置可用的 API Key。
