## 截图与 OCR

| 选项 | 作用 |
| --- | --- |
| 截图模式 | 选择普通截图或精确截图工具栏等模式，决定框选后的操作入口。 |
| OCR 识别模式 | 普通模式仅在进行截图操作的时候开启 OCR 引擎；快速模式会在首次截图操作后常驻后台（占用部分内存）；闲置释放模式在设定的时间区间内如果没有产生截图 OCR 操作，则自动释放资源（OCR引擎）。 |
| OCR 空闲超时 | OCR 窗口无操作后自动结束的时间，范围为 10 至 3600 秒，默认 300 秒。 |
| 关闭上一个 OCR 窗口 | 开启后再次启动 OCR 时自动关闭之前的 截图 OCR 窗口，避免窗口叠加。 |
| OCR 模型 | 下载、导入或删除各语言 OCR 模型；使用截图 OCR 前必须安装对应语言模型。 |
| 使用代理 | OCR 模型下载是否使用网络代理（在常规设置中配置代理地址）。 |

## 固定区域

固定区域保存屏幕上的常用矩形区域，适合反复截取同一位置。

| 字段 | 作用 |
| --- | --- |
| 名称 | 为固定区域设置易识别的名称。 |
| X、Y | 区域左上角在屏幕坐标中的位置。 |
| 宽度、高度 | 区域的尺寸。 |
| 启用 | 控制该区域是否出现在截图选择列表中。 |
