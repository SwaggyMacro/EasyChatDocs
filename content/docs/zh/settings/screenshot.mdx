## 截图与 OCR

| 选项 | 作用 |
| --- | --- |
| 截图模式 | 选择普通截图或精确截图工具栏等模式，决定框选后的操作入口。 |
| OCR 识别模式 | 普通模式仅在进行截图操作的时候开启 OCR 引擎；快速模式会在首次截图操作后常驻后台（占用部分内存）；闲置释放模式在设定的时间区间内如果没有产生截图 OCR 操作，则自动释放资源（OCR引擎）。 |
| OCR 空闲超时 | OCR 窗口无操作后自动结束的时间，范围为 10 至 3600 秒，默认 300 秒。 |
| 关闭上一个 OCR 窗口 | 开启后再次启动 OCR 时自动关闭之前的 截图 OCR 窗口，避免窗口叠加。 |
| OCR 模型 | 下载、导入或删除各语言 OCR 模型；使用截图 OCR 前必须安装对应语言模型。 |
| 使用代理 | OCR 模型下载是否使用网络代理（在常规设置中配置代理地址）。 |

## 图片翻译

图片翻译会先识别截图中的文字，再翻译并擦除原文字背景，将译文绘制回原图。以下选项位于 `设置 > 截图`，只影响图片翻译时的文字替换效果，不会改变 OCR 语言或翻译服务。

| 选项 | 作用 |
| --- | --- |
| 背景擦除模式 | 选择替换原文字前使用的背景擦除方式。 |
| 普通 | 使用自适应背景擦除，兼顾简单背景和带纹理的背景，不需要额外下载模型。适合大多数截图。 |
| 精确 (AOT-GAN) | 使用 AOT-GAN 模型擦除原文字背景，再写入译文。处理复杂背景时更适合；首次使用前需要下载 AOT-GAN 模型。 |
| 图片翻译模型 | 管理图片翻译专用模型。目前提供 AOT-GAN，约 61 MB，仅用于图片翻译时的文字替换背景擦除。 |

### 下载模型

1. 打开 `设置 > 截图`，在 `图片翻译` 区域将 `背景擦除模式` 切换为 `精确 (AOT-GAN)`。
2. 在 `图片翻译模型` 卡片中点击下载按钮，等待状态变为 `已下载`。
3. 下载过程中可以取消；下载失败时可重试，已安装的模型也可以删除。模型下载遵循 `设置 > 常规 > 网络代理`。

选择精确模式但模型尚未安装时，软件会提示先下载 AOT-GAN，或切换回普通模式。AOT-GAN 只负责擦除原文字背景，翻译仍使用 `设置 > 翻译` 中配置的 AI 大模型或机器翻译服务。

### 如何选择

| 场景 | 建议 |
| --- | --- |
| 偶尔翻译网页、软件界面或普通截图 | 使用 `普通`，无需下载额外模型。 |
| 需要尽量保留复杂图片背景，再把译文写回原图 | 下载 AOT-GAN 后使用 `精确 (AOT-GAN)`。 |

> 图片翻译需要可用的翻译源和对应语言的 OCR 模型；背景擦除模式只决定原文字被替换时的处理方式。

## 固定区域

固定区域保存屏幕上的常用矩形区域，适合反复截取同一位置。

| 字段 | 作用 |
| --- | --- |
| 名称 | 为固定区域设置易识别的名称。 |
| X、Y | 区域左上角在屏幕坐标中的位置。 |
| 宽度、高度 | 区域的尺寸。 |
| 启用 | 控制该区域是否出现在截图选择列表中。 |

> 该功能还未完善
