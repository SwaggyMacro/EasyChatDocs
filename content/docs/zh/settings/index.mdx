EasyChat 的设置窗口按功能分为 7 类。每个分类页面对应软件中的一个设置区域，并说明选项的用途、可选值和使用注意事项。

| 分类 | 主要内容 |
| --- | --- |
| [常规](./general) | 界面语言、默认语言、关闭行为、主题、开机自启动和网络代理 |
| [翻译](./translation) | AI 大模型、机器翻译、API Key |
| [划词](./selection) | 划词工具栏触发方式、可用操作、翻译源、提示词、大模型选择和程序过滤 |
| [语音](./speech) | ASR 模型 和 TTS 音色 |
| [截图](./screenshot) | 截图模式、OCR 模式、图片翻译背景擦除、固定区域和 OCR/图片翻译模型 |
| [结果窗口](./result) | 结果样式、朗读、自动关闭和显示速度 |
| [输入窗口](./input) | 输入窗口样式、发送方式、发送延迟和反向输入 |

设置会在修改后立即生效；API Key、代理地址等敏感或环境相关信息请按服务商要求填写。
