## 窗口样式

| 选项 | 作用 |
| --- | --- |
| 透明度级别 | 调整输入翻译窗口的不同透明效果。 |
| 背景色 | 设置输入区域背景色。 |
| 字体颜色 | 设置输入文字颜色。 |

## 发送行为

| 选项 | 作用 |
| --- | --- |
| 输入传递方式 | “模拟输入”逐字发送（仅适用于输入字符，如汉字等则不支持）；“粘贴”通过剪贴板快速写入；“消息”使用目标应用的消息接口（可能有少量应用不支持）。 |
| 按键发送延迟 | 模拟输入时相邻按键之间的间隔，单位为毫秒。目标应用响应较慢时可适当调小。 |
| 反向翻译(输入) | 交换当前输入翻译的源语言和目标语言，仅在输入翻译生效；例如当前源语言为英语，目标语言为中文时输入翻译会将您输入的中文翻译为英文。 |

## 语言

| 选项 | 作用 |
| --- | --- |
| 输入源语言 | 输入翻译窗口使用的源语言。 |
| 输入目标语言 | 输入翻译窗口使用的目标语言。 |
| 跟随全局语言 | 开启后忽略本页单独的语言选择，直接使用常规设置中的源语言和目标语言；关闭后使用本页配置。 |

输入翻译的快捷键在快捷键管理中配置；本页只决定窗口打开后的默认样式、语言和写回目标应用的方式。
