## 基本开关与触发

| 选项 | 作用 |
| --- | --- |
| 划词工具栏 | 总开关。开启后，选中文本会显示工具栏。关闭后仍可通过快捷键执行对应操作。 |
| 触发方式 | “双击”仅在双击选词时触发；“拖动选取”在鼠标拖选完成后触发；“全部”同时支持两种方式。 |
| 过滤模式 | “禁用”不筛选应用；“黑名单”仅排除程序名单；“白名单”仅在程序名单内启用。 |
| 程序名单 | 管理黑名单或白名单中的应用。名单按应用标识保存，可添加当前正在运行的程序。 |

## 工具栏操作

以下开关决定工具栏中显示哪些操作：

| 选项 | 作用 |
| --- | --- |
| 翻译 | 将选中文本翻译为目标语言。 |
| 纠错 | 检查拼写、语法和表达错误并给出修正。 |
| 润色 | 在不改变原意的前提下改善措辞和可读性。 |
| 总结 | 提取选中文本的主要信息。 |
| 解释 | 对词语、句子或概念给出详细说明。 |

## 翻译源

| 选项 | 作用 |
| --- | --- |
| 翻译引擎 | 选择 AI 大模型或机器翻译。机器翻译只提供普通翻译，纠错、润色、总结和解释需要 AI 大模型。 |
| AI 模型 | 在已配置的大模型中选择具体配置。 |
| 机器翻译 | 选择百度、腾讯、Google 或 DeepL 等已配置服务。 |
| 提示词 | 为翻译、纠错、润色、总结和解释分别选择提示词模板。 |
