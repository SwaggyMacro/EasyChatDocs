## 显示与朗读

| 选项 | 作用 |
| --- | --- |
| 结果窗口模式 | “经典”在屏幕顶部显示普通翻译结果；“词典”适合单词或短语，会显示更丰富的释义信息（需要 AI 大模型）。二者均支持 `Markdown` 渲染。 |
| 朗读模式 | 不朗读、朗读源语言、朗读目标语言或两者都朗读。音色由语音设置中的 TTS 配置决定。 |
| 字体、字号、字体颜色 | 设置结果文本的字体外观。 |
| 透明度 | 调整结果窗口整体透明程度。 |
| 背景色 | 设置内容区域背景色。 |
| 窗口背景色 | 设置窗口外层背景色。 |

## 自动行为

| 选项 | 作用 |
| --- | --- |
| 自动关闭延迟 | 结果窗口显示后自动关闭的时间（毫秒）。设置为较大值可留出更多阅读时间。 |
| 自动计算延迟 | 开启后，结果窗口会根据内容长度自动计算关闭延迟(使用每字符毫秒数计算 `毫秒/字`)；关闭后使用“自动关闭延迟”设置的固定值。 |
| 毫秒/字 | 控制自动计算延迟时使用的每字符毫秒数。 |
