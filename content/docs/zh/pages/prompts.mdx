提示词页面用于维护发送给 AI 大模型的指令模板。它只影响依赖 AI 大模型的功能，机器翻译无法使用提示词。

## 页面操作

| 操作 | 作用 |
| --- | --- |
| 新增提示词 | 创建一条包含名称和内容的提示词模板。 |
| 搜索 | 按名称或提示词角色筛选条目。 |
| 编辑 | 修改模板名称和内容。 |
| 删除 | 移除不再使用的模板。被其他配置引用时，请先改选其他提示词。 |
| 设为默认 | 将条目设为全局默认提示词。 |

## 如何生效

翻译、划词工具栏、实时语音识别和文本辅助可以选择提示词。某个页面未指定专用提示词时，会使用这里设置的默认提示词。建议为不同工作流分别建立简洁翻译、术语翻译、语法纠错、写作润色等模板。

提示词应明确说明任务、角色；过长或互相矛盾的指令可能降低模型响应的稳定性。

<Callout type="info" title="提示词角色">
  - 提示词角色是指模型在执行任务时扮演的身份或立场，例如“专业翻译”、“英语教师”、“写作助理”等。明确的角色有助于模型理解任务背景，从而生成更符合预期的输出；  
  - 软件本身附带 26 种预设提示词，用户可以直接使用这些提示词。    
</Callout>

## 提示词参数

- `[源语言]`：指示模型输入文本的语言，会在调用大模型时替换为当前设置的源语言。  
  英文参数为 `[SourceLang]`
- `[目标语言]`：指示模型输出文本的语言，会在调用大模型时替换为当前设置的目标语言。  
  英文参数为 `[TargetLang]`
