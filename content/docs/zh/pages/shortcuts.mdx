快捷键页面用于创建全局快捷键。它们可在其他应用前台时触发 EasyChat 功能，前提是组合键没有被系统或目标软件占用。

## 基础快捷键

| 类型 | 作用 |
| --- | --- |
| 截图翻译 | 框选屏幕区域，识别文字后翻译。 |
| 截图 OCR | 框选屏幕区域，仅进行文字识别。 |
| 输入翻译 | 打开输入翻译窗口，将翻译结果写回当前输入位置。 |
| 划词翻译 | 对当前选中的文本执行翻译。 |
| 快捷翻译 | 打开可直接输入文本的快速翻译窗口。 |
| 快捷纠正 | 打开文本纠错窗口。 |

快捷翻译和快捷纠正可选择“读取选中文本”，触发时自动读取当前选区作为初始内容。

## 语种切换快捷键

用于快速切换全局源语言和目标语言的语种，适合阅读不同语言内容时使用。

## 编辑条目

每个快捷键条目均包含功能类型、组合键、启用状态和备注。部分功能还可设置翻译引擎、模型、源/目标语言、是否替换当前输入、输入前后按键或文本辅助模式。禁用条目会保留配置但不会使快捷键生效。

<Callout type="warning" title="冲突处理">
  若快捷键无法触发，请换用未被 Windows、输入法或目标应用占用的组合键。
</Callout>
