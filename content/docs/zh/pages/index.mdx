EasyChat 主窗口左侧为页面导航。页面按使用流程排列：先在主页确认翻译状态，再配置设置和快捷键，之后按需要使用提示词、实时语音识别或文本辅助。

| 页面 | 用途 |
| --- | --- |
| [主页](./home) | 查看配置状态、快速切换语言和进入常用功能。 |
| [设置](./settings) | 管理常规、翻译、划词、语音、截图、结果和输入配置。 |
| [快捷键](./shortcuts) | 添加和维护全局功能快捷键。 |
| [提示词](./prompts) | 管理 AI 功能使用的提示词模板。 |
| [实时语音识别](./speech-recognition) | 将系统播放的声音识别并显示为实时字幕。 |
| [文本辅助](./text-assist) | 使用 AI 完成翻译、纠错和写作辅助。 |
| [关于](./about) | 查看版本信息、更新和项目相关链接。 |

<Callout type="info" title="提示">
  “设置”页面负责保存全局配置；“快捷键”“提示词”“实时语音识别”和“文本辅助”则是独立的工作页面。
</Callout>
