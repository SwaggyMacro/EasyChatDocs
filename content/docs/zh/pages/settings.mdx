---
title: 设置
description: 集中管理 EasyChat 的全局配置、翻译服务和界面行为。
icon: Settings
---

设置页面是 EasyChat 的配置中心，支持搜索具体选项，并按以下区域组织：

| 区域 | 管理内容 |
| --- | --- |
| 常规 | 界面和原生语言、主题、关闭行为、开机启动、数据目录、网络代理。 |
| 翻译 | AI 大模型、机器翻译服务、API Key、模型和单服务代理。 |
| 划词工具栏 | 工具栏开关、触发方式、可用操作、翻译源与应用过滤。 |
| 语音 | TTS 提供商、音色，以及 ASR 模型的下载和导入。 |
| 截图 | 截图模式、OCR 识别、固定区域和 OCR 模型。 |
| 结果窗口 | 翻译结果的样式、朗读、自动关闭和显示速度。 |
| 输入窗口 | 输入翻译窗口样式、传递方式、发送延迟和语言行为。 |

详细字段说明见 [设置说明](../settings)。修改设置后会立即生效；模型和 API Key 的正确性可通过翻译服务的“测试连接”验证。
