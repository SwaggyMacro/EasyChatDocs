EasyChat can recognize audio playing on your Windows system, translate it, and display the result as subtitles. Ten recognition languages are supported.

## How to use it


<Callout title="ASR model required" type="warning">
  Currently, the ASR models for real-time speech recognition can be downloaded directly within the app (download source: GitHub). Users in mainland China may experience download failures due to network issues. You can configure a proxy in `Settings` -> `General` -> `Network Proxy` before trying again, or use tools like Watt Toolkit to accelerate GitHub downloads;   
    Alternatively, you can manually import models downloaded from [GitHub](https://github.com/SwaggyMacro/MicroASR/releases/tag/models-v1), [Google Drive](https://drive.google.com/drive/folders/19pmknOmBA07HiVrUQljz1Jh3t3Jy8aDF?usp=sharing), or the group files in our [QQ Group](https://qm.qq.com/q/rXrrefKXNQ).
</Callout>

1. Under `Setting > Speech > ASR models`, import the required model folder or supported model archive.
   ![Import an ASR model](../../images/zh/config-asr-import.png)
2. Open `Speech Recognition`, choose the audio source and recognition options, and start recognition. Enable the `Subtitle Window` to show the original text or translation over other applications.
   > The audio source can be limited to a specific process so sounds from other applications are ignored.

   ![Start speech recognition](../../images/zh/asr-start.png)
   ![Speech recognition subtitles](../../images/zh/asr-subtitle.png)

## Supported languages
10 recognition languages are supported, each with its own ASR model. Please download the corresponding model before using the feature.

| Korean | ko-KR |
| German | de-DE |
| Danish | da-DK |
| Spanish | es-ES |
