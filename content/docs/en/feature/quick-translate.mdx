## How to use it

Use Quick Translate either from the translation tab on the `Translate / Correct` page or from a global shortcut.

On the page or in the shortcut window, you can choose the target language and translation engine and enable `Detailed notes`. The detailed view can include meanings, collocations, key words, uncommon words, and usage tips, and requires an AI model.

### Shortcut

1. On the `Shortcut` page, add a shortcut for Quick Translate. Enable `Read selected text` if the shortcut should copy the current selection automatically.
2. Press the shortcut, then enter text or translate the selection loaded into the window.
