Typing Translate opens from a global shortcut. Enter text in your language and EasyChat translates it, then delivers the result to the currently focused application.

## How to use it

1. Open `Shortcut` from the sidebar and add a shortcut whose action is `Typing Translate`.
2. Focus the text field in the target application, then press the shortcut.
3. Enter the text to translate. EasyChat detects the language, translates the text, and delivers it to the target application.

## Related settings
The input window supports:
1. Setting the source and target languages, or choosing `Follow Configuration` to use the globally configured language direction.
2. Previewing the translation result by clicking the eye icon next to the close button in the lower right corner of the input window.
![Typing Translate window](../../images/zh/input-preview.png)

<Callout title="Note" type="warning">
    The preview supports hovering over each word to see its definition (only available when the translation source is an AI model), and clicking to jump to the dictionary.
    ![Typing Translate window](../../images/zh/input-preview-2.png)
</Callout>

## Requirements and language settings

1. Configure at least one working translation source, either an AI model or machine translation.
2. In the input window, choose the source and target languages directly, or enable `Follow Configuration` to use the globally configured language direction.

See [Input Window settings](../settings/input) for text delivery, simulated keys, and language options.
