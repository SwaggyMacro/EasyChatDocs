Screenshot OCR recognizes all text in a captured area. In the OCR window, select any recognized text to copy, translate, or explain it, or translate the complete image.

## How to use it

There are two ways to open Screenshot OCR.

### Shortcut

On the `Shortcut` page, add a shortcut whose action is `Screenshot OCR`. Press it and select the screen area to recognize.

### Screenshot toolbar

Under `Setting > Screenshot > Screenshot Mode`, choose the precise capture mode with a toolbar. After selecting an area with the screenshot translation shortcut, choose the `OCR` action on the capture toolbar.

An OCR model for the text language must be installed under `Setting > Screenshot > OCR models`.
