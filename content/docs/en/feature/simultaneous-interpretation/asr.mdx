## Install an ASR model

Before using Audio Translation, [install an ASR model](./#install-an-asr-model).

## How to use it

Open `Live Translation` -> `Audio Translation`, choose the options you need, select **Start Recognition**, and enable the floating subtitle window. EasyChat recognizes audio and video playing on your system and displays the translated result as subtitles.

> You can limit recognition to a particular process with the audio source option.

## Use cases

<Cards>
  <Card title="Videos and live streams without subtitles" icon={<Video />}>
    Watch foreign-language videos and live streams with translated subtitles generated from system audio, so you can follow news and entertainment as they happen.

  <Card title="International meetings and online classes" icon={<Presentation />}>
    When using Zoom, Teams, or an overseas online course, select the meeting app process for focused, real-time translated subtitles without interference from other applications.

  <Card title="Podcasts and audio-only content" icon={<Headphones />}>

  </Card>

  <Card title="Immersive listening practice" icon={<Subtitles />}>
