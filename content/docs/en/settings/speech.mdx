## ASR models and recognition

| Option | Purpose |
| --- | --- |
| ASR models | Downloads, imports, or deletes local speech-recognition models. Speech recognition is unavailable when no model is installed. |

## TTS

| Option | Purpose |
| --- | --- |
| TTS Provider | Selects the text-to-speech service. |
| Voice configuration | Selects a voice for each language and provider. The result window can read the source language, target language, or both. |
