## Languages

| Option | Purpose |
| --- | --- |
| Display Language | Sets the language used by the EasyChat interface, buttons, and messages. |
| Native Language | Specifies the language you are familiar with. Translation and speech-recognition features use it as a reference for the default target or auxiliary language. |
| Source Lang | Sets the global translation source language. When automatic detection is selected, the translation engine determines the input language. |
| Target Lang | Sets the global translation target language. Typing Translate, Screenshot Translation, and selection features use this value when configured to follow global settings. |

## Closing and startup

| Option | Purpose |
| --- | --- |
| Exit Action | Chooses what happens when the main window is closed: ask, exit the application, or minimize to the tray. When minimized to the tray, EasyChat and its shortcuts continue running. |
| Auto Start | Controls whether EasyChat starts automatically after you sign in to Windows. |
| Full Screen | Displays the main window in full-screen mode. |

## Appearance

| Option | Purpose |
| --- | --- |
| Base theme | Follows the system theme or uses the light or dark theme. |
| Color theme | Selects a preset accent palette for the base theme. A custom theme uses the color values below. |
| Primary Color | Sets the interface's primary accent color. Enter a valid color value such as `#2F80ED`. |
| Accent Color | Sets the accent color used for buttons, selected states, and other controls. |

## Application data and network

| Option | Purpose |
| --- | --- |
| Application data | Shows or changes the location where all local data, including settings, prompts, and model lists, is stored. |
| Network Proxy | Uses the system proxy, no proxy, or a custom proxy. Custom mode requires a proxy address. This proxy applies to general network requests such as model downloads, speech models, and updates. AI models and machine translation services separately control whether their own requests use the proxy. |
