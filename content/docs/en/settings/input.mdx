## Window appearance

| Option | Purpose |
| --- | --- |
| Transparency Level | Adjusts the input window's transparency effect. |
| Background Color | Sets the input area's background color. |
| Font Color | Sets the input text color. |

## Delivery behavior

| Option | Purpose |
| --- | --- |
| Text Delivery Mode | `Simulated input` sends characters one by one and only supports characters that can be typed directly; characters such as Chinese are not supported. `Paste` writes quickly through the clipboard. `Message` uses the target application's message interface, which a small number of applications may not support. |
| Key Send Delay | Sets the interval between simulated keystrokes in milliseconds. For a target application that responds slowly, this value can be decreased as needed. |
| Reverse Language | Swaps the source and target languages for Typing Translate only. For example, if the source is English and the target is Chinese, the Chinese text you enter is translated into English. |

## Languages

| Option | Purpose |
| --- | --- |
| Input source language | Sets the source language used by the Typing Translate window. |
| Input target language | Sets the target language used by the Typing Translate window. |
| Follow Configuration | When enabled, ignores the separate language selections on this page and uses the source and target languages from General settings. When disabled, uses this page's configuration. |

Configure the Typing Translate shortcut on the `Shortcut` page. This page controls only the default appearance, languages, and method used to write text back to the target application after the window opens.
