EasyChat settings are divided into seven categories. Each page below corresponds to one section in the application and explains the purpose, available values, and important usage notes for its options.

| Category | Main options |
| --- | --- |
| [General](./general) | Display language, default languages, closing behavior, theme, automatic startup, and network proxy |
| [Translation](./translation) | AI models, machine translation, and API keys |
| [Selection](./selection) | Selection Toolbar triggers, available actions, translation sources, prompts, AI model, and application filtering |
| [Speech](./speech) | ASR models and TTS voices |
| [Screenshot](./screenshot) | Screenshot mode, OCR mode, fixed areas, and OCR models |
| [Result Window](./result) | Result appearance, read-aloud behavior, automatic closing, and display duration |
| [Input Window](./input) | Input window appearance, delivery method, send delay, and reverse input translation |

Settings take effect immediately after they are changed. Enter API keys, proxy addresses, and other sensitive or environment-specific values according to the service provider's requirements.
