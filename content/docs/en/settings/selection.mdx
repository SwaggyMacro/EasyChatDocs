## Activation and triggers

| Option | Purpose |
| --- | --- |
| Selection Toolbar | The master switch. When enabled, selecting text displays the toolbar. When disabled, the same actions remain available through shortcuts. |
| Selection Method | `Double-click` triggers only when a word is selected by double-clicking; `Drag selection` triggers after selecting text by dragging; `All` enables both methods. |
| Selection Scope | `Disabled` does not filter applications; `Blacklist` excludes applications on the list; `Whitelist` enables the toolbar only in listed applications. |
| Application List | Manages applications in the blacklist or whitelist. Entries are stored by application identity, and currently running applications can be added. |

## Toolbar actions

These switches determine which actions appear in the toolbar:

| Option | Purpose |
| --- | --- |
| Translate | Translates the selected text into the target language. |
| Correct | Checks spelling, grammar, and expression and provides corrections. |
| Polish | Improves wording and readability without changing the original meaning. |
| Summary | Extracts the main information from the selected text. |
| Explain | Provides a detailed explanation of a word, sentence, or concept. |

## Translation source

| Option | Purpose |
| --- | --- |
| Translate Engine | Selects an AI model or machine translation. Machine translation provides general translation only; correction, polishing, summaries, and explanations require an AI model. |
| AI Model | Selects a specific model from the configured AI models. |
| Machine Trans | Selects a configured service such as Baidu, Tencent, Google, or DeepL. |
| Prompt | Selects separate prompt templates for translation, correction, polishing, summaries, and explanations. |
