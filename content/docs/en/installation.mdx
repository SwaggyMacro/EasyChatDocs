## Download

Visit the [GitHub Releases page](https://github.com/SwaggyMacro/EasyChat/releases) and download the latest EasyChat release.

<Callout type="info" title="Windows support">
  EasyChat currently supports Windows only. macOS and Linux support is planned.
</Callout>

## Installation options

### Installer

Download and run `EasyChat-Win-<version>-Setup.msi`.

> The installer is recommended because it creates the appropriate system shortcuts.

### Portable version

Download `EasyChat-Win-<version>-Portable.zip`, extract the archive, and run `EasyChat.exe`. No installation is required.
