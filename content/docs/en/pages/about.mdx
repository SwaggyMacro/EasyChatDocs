`About` shows the installed EasyChat version and the latest available version. When an update is found, open the Releases page to review and download it.

The page also links to the project website, source repository, issue tracker, and community resources for release notes, problem reports, and support.

<Callout type="info" title="Update checks">
  Automatic update checks require network access. If a check fails, verify `Network Proxy` under General settings and confirm that the release service is reachable.
</Callout>
