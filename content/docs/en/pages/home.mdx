Home is the default page after EasyChat starts. It shows whether the application is ready to translate and provides quick access to common tasks.

## Translation status

Home shows the current translation engine, selected AI model or machine translation service, and whether configuration is complete. If no source is available, use `Configure translation source` to open `Setting > Translation`.

## Language direction

Choose the global `Source Lang` and `Target Lang`, or use `Swap` to exchange them. Typing Translate and other features configured to follow the global languages use this direction.

## Configuration checks

The first-time guide checks these requirements:

| Check | Completion condition |
| --- | --- |
| Translation engine | An AI model is selected and usable, or a configured machine translation service is selected. |
| Shortcut | At least one shortcut is enabled. |

You can dismiss the guide after setup without changing any feature behavior.

## Quick actions

Home provides direct links to `Speech Recognition`, `Translate / Correct`, `Shortcut`, and `Prompts`, plus About and update checks.
