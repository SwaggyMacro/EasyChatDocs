The sidebar in the main EasyChat window provides access to these pages:

| Page | Purpose |
| --- | --- |
| [Home](./home) | Review configuration status, change the language direction, and open common features. |
| [Setting](./settings) | Manage general behavior, translation services, Selection Toolbar, speech, screenshots, result windows, and input windows. |
| [Shortcut](./shortcuts) | Add and maintain global action shortcuts. |
| [Prompts](./prompts) | Manage prompt templates used by AI features. |
| [Speech Recognition](./speech-recognition) | Recognize system audio and display live source or translated subtitles. |
| [Translate / Correct](./text-assist) | Translate text, correct errors, and get AI writing assistance. |
| [About](./about) | View version information, check for updates, and open project links. |

<Callout type="info" title="Configuration and work pages">
  `Setting` stores global configuration. `Shortcut`, `Prompts`, `Speech Recognition`, and `Translate / Correct` are separate pages for managing or performing specific tasks.
</Callout>
