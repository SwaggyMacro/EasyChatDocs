`Setting` is the EasyChat configuration center. Use its search field to locate an option, or browse these sections:

| Section | What it manages |
| --- | --- |
| General | Display and native languages, exit behavior, startup, application data, and network proxy. |
| Translation | AI models, machine translation services, API keys, models, and per-service proxy behavior. |
| Selection | Selection Toolbar activation, actions, translation sources, prompts, and application filtering. |
| Speech | ASR model downloads and imports, TTS provider, and voice mappings. |
| Screenshot | Capture mode, OCR behavior, OCR models, and fixed areas. |
| Result Window | Translation result layout, appearance, read-aloud behavior, and automatic closing. |
| Input Window | Typing Translate window appearance, delivery method, key delay, and language behavior. |

See [Settings Reference](../settings) for field-level details. Most changes take effect immediately. Use `Test Connection` to validate a translation service's endpoint, model, and credentials.
